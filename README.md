# maze-escape

Відкрийте `index.html` у браузері. Сервер і встановлення залежностей не потрібні.

- `index.html` — розмітка та інтерфейс.
- `styles.css` — стилі.
- `game.js` — логіка гри та Canvas-рендеринг.
- `assets/` — згенеровані текстури й спрайти (три атласи 4×4).

Атласи містять стіни, двері, підлогу, ворогів, предмети, зброю, меблі та
декорації. Освітлення, туман, кров, подряпини й погодні ефекти малюються кодом.
Поки картинки завантажуються або якщо вони недоступні, працює початкова графіка.

Перевірка: `node --check game.js`. Для перевірки у Chromium задайте
`CHROME_PATH` (шлях до chrome.exe) і виконайте `node tests/smoke.cjs`.
